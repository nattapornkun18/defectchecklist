# Defect Checklist — Deluxe King (Right)

ฟอร์มตรวจ defect แบบเว็บ ใช้แทนการปริ้นเอกสารสีทุกครั้งที่ตรวจห้อง
เปิดบนมือถือหรือแท็บเล็ต แตะที่หมุดบนแปลนห้อง → เลือกผลตรวจ → บันทึกลง Google Sheet

ใช้กับห้องที่ลงท้ายด้วย **10** (310, 410, … 2010) room type **Deluxe King — Right**

---

## ใช้งานยังไง (สำหรับผู้ตรวจ)

1. เปิดลิงก์เว็บบนมือถือ แล้ว **Add to Home Screen** ไว้ จะเปิดได้เหมือนแอป
2. เลือก **ห้อง / รอบตรวจ / ชื่อผู้ตรวจ** ที่หัวฟอร์ม (ระบบจำชื่อผู้ตรวจไว้ให้)
3. แตะที่ **หมุดตัวเลขบนแปลนห้อง** → หน้าต่างรายการตรวจของโซนนั้นจะเลื่อนขึ้นมา
4. แต่ละข้อเลือก **✓ ผ่าน / ✗ Defect / – N/A** (แตะซ้ำที่ปุ่มเดิม = ยกเลิกคำตอบ)
   - ถ้าเลือก **Defect** จะมีช่องให้ใส่ **จำนวนจุดที่พบ**, **รายละเอียด/ตำแหน่ง** และ **ถ่ายรูปแนบ** (สูงสุด 3 รูป/ข้อ)
5. ปุ่ม **✓ ผ่านทั้งโซน** = ตั้งข้อที่ยังไม่ได้ตอบในโซนนั้นเป็น "ผ่าน" ทั้งหมด (ใช้ตอนโซนนั้นไม่มีปัญหา)
6. ปุ่ม **โซนถัดไป →** เดินตามลำดับ 1 → 7 จนครบ
7. กด **บันทึกลง Sheet** ที่แถบล่าง

### สีของหมุดบนแปลน

| สี | ความหมาย |
|---|---|
| 🔵 น้ำเงิน | ยังตรวจไม่ครบ |
| 🟢 เขียว | ตรวจครบทุกข้อ ไม่พบ defect |
| 🔴 แดง | พบ defect (ตัวเลขมุมบนขวาคือจำนวนรายการ) |

### จุดที่ควรรู้

- **ข้อมูลถูกเก็บในเครื่องอัตโนมัติทุกครั้งที่แตะ** ปิดเบราว์เซอร์ / แบตหมด แล้วเปิดใหม่ ข้อมูลยังอยู่
- **ตรวจแบบไม่มีเน็ตได้** ถ้ากดบันทึกตอนไม่มีสัญญาณ ระบบจะเก็บคิวไว้ แล้วขึ้นแถบเหลืองเตือน พอกลับมามีเน็ตให้กด "ลองส่งอีกครั้ง" (หรือระบบส่งเองเมื่อกลับออนไลน์)
- **บันทึกซ้ำได้** ถ้าตรวจเพิ่มแล้วกดบันทึกอีกครั้ง ระบบจะ **แทนที่** ข้อมูลเดิมของการตรวจครั้งนั้น ไม่เกิดแถวซ้ำใน Sheet
  (ยึดจาก ห้อง + วันที่ + รอบตรวจ — ถ้าเปลี่ยน 3 อย่างนี้จะนับเป็นการตรวจครั้งใหม่)
- **แต่ละห้องแยกร่างกัน** สลับห้องไปมาได้โดยข้อมูลไม่ปนกัน
- **ปุ่ม 🖨** = พิมพ์หรือ Save as PDF สรุปผลตรวจ (เผื่อต้องส่งเอกสารให้ผู้รับเหมาเซ็น)
- บันทึกลง Sheet เฉพาะข้อที่เป็น **Defect** และ **N/A** — ข้อที่ผ่านจะนับรวมไว้ในแถวสรุปเท่านั้น เพื่อไม่ให้ Sheet บวม

## ติดตั้งครั้งแรก (ทำครั้งเดียว)

### 1) เตรียม Google Sheet + Apps Script

1. เปิด Google Sheet ที่จะใช้เก็บข้อมูล (จะสร้างไฟล์ใหม่หรือใช้ไฟล์เดิมก็ได้)
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดใน `Code.gs` เดิมทิ้ง แล้ววางเนื้อหาจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) ลงไปทั้งหมด → กด 💾 Save
4. กด **Deploy → New deployment**
   - คลิกฟันเฟือง ⚙ ข้าง "Select type" → เลือก **Web app**
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`  ← สำคัญ ถ้าเลือก "Anyone with Google account" หน้าเว็บจะส่งข้อมูลไม่ได้
   - กด **Deploy** → กด **Authorize access** → เลือกบัญชี → "Advanced" → "Go to (ชื่อโปรเจกต์) (unsafe)" → **Allow**
     (ที่ขึ้นเตือนเพราะเป็นสคริปต์ที่เราเขียนเอง ยังไม่ได้ผ่านการรับรองจาก Google — ปกติ)
5. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) เก็บไว้

> ระบบจะสร้างชีท `Inspections` และ `DefectLog` ให้อัตโนมัติตอนบันทึกครั้งแรก
> ถ้าอยากสร้างล่วงหน้า ให้เลือกฟังก์ชัน `setupSheets` ใน Apps Script แล้วกด Run

### 2) เอาหน้าเว็บขึ้นออนไลน์

วิธีที่ง่ายที่สุดคือ **GitHub Pages** (ฟรี ไม่ต้องมีเซิร์ฟเวอร์):

1. ใน repo นี้ → **Settings → Pages**
2. **Source:** `Deploy from a branch`
3. **Branch:** เลือก branch ที่มีโค้ดนี้ + โฟลเดอร์ `/ (root)` → **Save**
4. รอ 1–2 นาที จะได้ลิงก์หน้าตาแบบ
   `https://nattapornkun18.github.io/defectchecklist/`

*(หรือจะลากไฟล์ทั้งโฟลเดอร์ไปวางบน Netlify Drop ก็ได้ ไม่ต้องตั้งค่าอะไรเลย)*

### 3) เชื่อมหน้าเว็บกับ Sheet

1. เปิดลิงก์หน้าเว็บ → กดปุ่ม **⚙** มุมขวาบน
2. วาง **Web app URL** จากข้อ 1)
3. กด **ทดสอบการเชื่อมต่อ** — ต้องขึ้นไฟเขียวพร้อมชื่อไฟล์ Sheet
4. กด **บันทึก**

ตั้งค่านี้เก็บอยู่ในเครื่องของแต่ละคน → **ผู้ตรวจแต่ละคนต้องทำข้อ 3 นี้ครั้งเดียวบนมือถือของตัวเอง**

## ข้อมูลที่บันทึกลง Sheet

### ชีท `Inspections` — สรุป 1 แถวต่อการตรวจ 1 ครั้ง

`Timestamp` · `InspectionID` · `Room` · `RoomType` · `Round` · `Inspector` · `Date` ·
`TotalItems` · `Checked` · `Pass` · `Defect` · `N/A` · `DefectQty` · `Progress %` · `Note`

### ชีท `DefectLog` — 1 แถวต่อ 1 รายการที่เป็น Defect หรือ N/A

`Timestamp` · `InspectionID` · `Room` · `Round` · `Inspector` · `Date` ·
`ZoneNo` · `Zone` · `ItemNo` · `Item (TH)` · `Item (EN)` ·
`Status` · `Qty` · `Detail` · `Photos`

รูปถ่ายจะถูกอัปโหลดเข้าโฟลเดอร์ Google Drive ชื่อ **Defect Checklist Photos**
แล้วใส่ลิงก์ไว้ในคอลัมน์ `Photos` (ตั้งเป็น "ใครมีลิงก์ก็ดูได้" อัตโนมัติ)

จากสองชีทนี้ทำ Pivot Table ต่อได้เลย เช่น นับ defect ต่อห้อง / ต่อโซน / ต่อผู้รับเหมา

## แก้ไขรายการตรวจ

รายการตรวจทั้งหมดอยู่ใน **[`js/checklist.js`](js/checklist.js) ไฟล์เดียว** แก้ที่นั่นที่เดียวพอ

```js
const ROOM_TYPE = 'Deluxe King — Right';        // ชื่อ room type บนหัวฟอร์ม
const ROOMS = [...];                            // รายชื่อห้อง
const ROUNDS = [...];                           // รอบตรวจ

const ZONES = [
  {
    id: 'bath',                                 // ห้ามซ้ำกับโซนอื่น
    name: 'ห้องน้ำ',
    en: 'Bathroom',
    pin: { x: 288, y: 528 },                    // ตำแหน่งหมุดบนแปลน
    items: [
      { th: 'ข้อความภาษาไทย', en: 'English text' },
      // ...
    ],
  },
];
```

- **เพิ่ม/ลบ/แก้ข้อความรายการตรวจ:** แก้ในอาเรย์ `items` ได้เลย เลขข้อไล่ตามลำดับในอาเรย์อัตโนมัติ
- **ย้ายตำแหน่งหมุด:** แก้ `pin` — พิกัดอ้างอิงระบบ SVG `viewBox="0 0 420 660"`
  (x: 0 = ซ้ายสุด → 420 = ขวาสุด, y: 0 = บนสุด → 660 = ล่างสุด)
- **แก้รูปแปลนห้อง:** แก้ `<svg class="plan-svg">` ใน [`index.html`](index.html) — วาดด้วย SVG ล้วน ไม่ต้องใช้ไฟล์รูป
- **ทำ room type อื่น** (เช่น Deluxe Left / Suite): ก๊อป repo นี้ แก้ `checklist.js` + แปลนใน `index.html` แล้ว deploy เป็นอีกลิงก์ ชี้ Web App URL เดิมได้ เพราะคอลัมน์ `RoomType` แยกให้อยู่แล้ว

> ⚠️ ถ้าแก้ `id` ของโซน ค่าที่เก็บไว้ในเครื่องของร่างที่ยังตรวจค้างอยู่จะอ่านไม่เจอ
> ควรแก้ตอนที่ไม่มีใครค้างการตรวจอยู่ (ข้อมูลที่บันทึกลง Sheet ไปแล้วไม่กระทบ)

## โครงสร้างไฟล์

```
index.html            หน้าเว็บ + แปลนห้อง (SVG)
css/app.css           สไตล์ทั้งหมด รวมสไตล์สำหรับพิมพ์
js/checklist.js       ← ข้อมูลรายการตรวจ (แก้ไฟล์นี้เพื่อเปลี่ยนเนื้อหาฟอร์ม)
js/app.js             ตรรกะ: บันทึกในเครื่อง, คิวออฟไลน์, ส่งขึ้น Sheet
apps-script/Code.gs   สคริปต์ฝั่ง Google Sheet
```

ไม่ต้อง build ไม่ต้องลง dependency อะไรเลย — เป็น static file ล้วน วางที่ไหนก็รันได้

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ทดสอบการเชื่อมต่อขึ้น `Failed to fetch` | Deployment ตั้ง "Who has access" ไม่ได้เป็น **Anyone** หรือ URL ไม่ได้ลงท้ายด้วย `/exec` |
| แก้ `Code.gs` แล้วแต่พฤติกรรมไม่เปลี่ยน | ต้อง **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** ทุกครั้ง (แค่ Save ไม่พอ) |
| ขึ้น "พื้นที่เก็บในเครื่องเต็ม" | รูปถ่ายสะสมเยอะเกินไป — กดบันทึกลง Sheet ให้เรียบร้อยแล้วกด "ล้าง" ห้องที่ตรวจเสร็จแล้ว |
| อยากบันทึกเร็วขึ้นตอนเน็ตช้า | ปุ่ม ⚙ → เอาเครื่องหมายถูกออกจาก "แนบรูปไปด้วย" |
| ข้อมูลใน Sheet ซ้ำ | เกิดเมื่อเปลี่ยน **วันที่** หรือ **รอบตรวจ** แล้วบันทึกใหม่ ซึ่งระบบตั้งใจให้นับเป็นการตรวจคนละครั้ง |

## หมายเหตุ

รายการตรวจใน `js/checklist.js` ตอนนี้เป็น **ชุดมาตรฐานห้อง Deluxe** ที่ร่างขึ้นเป็นค่าตั้งต้น
ยังไม่ใช่รายการจริงจากฟอร์มกระดาษเดิม — เพราะเข้าถึงไฟล์ Google Sheet ต้นฉบับไม่ได้
เมื่อได้เนื้อหาจริงแล้วให้แทนที่ในไฟล์นั้นไฟล์เดียว ส่วนอื่นของระบบไม่ต้องแก้
