# Custom Menu ใน Google Sheet — มันคืออะไร ทำอะไรได้บ้าง

เมนู **Defect Checklist** ที่โผล่บนแถบเมนูของชีท (ต่อจาก Help) เรียกว่า
**Custom Menu** หรือ **เมนูกำหนดเอง** สร้างด้วย **Google Apps Script**

Apps Script คือ JavaScript ที่รันบนเซิร์ฟเวอร์ของ Google ผูกกับไฟล์ชีท
เข้าถึงได้ที่ **Extensions → Apps Script**

---

## สร้างยังไง — โค้ดสั้นที่สุดที่ใช้ได้จริง

```javascript
// ชื่อฟังก์ชันต้องเป็น onOpen เท่านั้น Google ถึงจะเรียกให้เองตอนเปิดชีท
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('ชื่อเมนูของเรา')          // ข้อความที่โผล่บนแถบเมนู
    .addItem('ข้อความในเมนู', 'ชื่อฟังก์ชัน')  // กดแล้วเรียกฟังก์ชันนี้
    .addToUi();                            // สั่งให้แสดงจริง
}

function ชื่อฟังก์ชัน() {
  SpreadsheetApp.getUi().alert('สวัสดี');
}
```

**สำคัญ:** `onOpen` ทำงานตอน **เปิดชีท** เท่านั้น
แก้โค้ดแล้วต้อง **Ctrl+S แล้วรีเฟรชหน้าชีท** เมนูถึงจะอัปเดต

### ตัวช่วยจัดเมนู

```javascript
.addItem('ชื่อ', 'ฟังก์ชัน')      // รายการปกติ
.addSeparator()                  // เส้นคั่น
.addSubMenu(                     // เมนูย่อยซ้อนอีกชั้น
  SpreadsheetApp.getUi().createMenu('เมนูย่อย').addItem('...', '...')
)
```

## เมนูของระบบนี้ทำอะไรบ้าง

| รายการ | ฟังก์ชัน | ทำอะไร |
|---|---|---|
| อัปเดตชีทสรุปรวม | `buildSummarySheet` | สร้างแท็บ "สรุปรวม" ใหม่ทั้งแผ่นจากข้อมูลล่าสุด |
| 🗑 ลบผลตรวจของแถวที่เลือก | `deleteSelectedInspection` | อ่าน InspectionID จากแถวที่เคอร์เซอร์อยู่ → ยืนยัน → ลบทั้ง 2 ชีท → สร้างสรุปใหม่ |
| ลบผลตรวจ (พิมพ์ InspectionID เอง) | `deleteInspectionByPrompt` | เหมือนข้างบน แต่พิมพ์ ID เอง เผื่อหาแถวไม่เจอ |
| ดูข้อผิดพลาดล่าสุดของชีทสรุป | `showLastSummaryError` | แสดง error ล่าสุดที่เก็บไว้ตอนสร้างสรุปไม่สำเร็จ |
| 🔍 ตรวจสอบระบบ (diagnose) | `diagnose` | รายงานสถานะทั้งระบบ — แท็บที่มี จำนวนแถว หมวดที่รู้จัก สถานะรหัส |
| 🔑 ตั้งรหัสเข้าใช้งาน | `setupPins` | ถามรหัสผู้ดูแล/ผู้ตรวจ แล้วเก็บใน Script Properties |
| ยกเลิกระบบรหัส | `clearPins` | ลบรหัสทิ้ง กลับไปเปิดให้ทุกคนใช้ |
| สร้างชีทที่จำเป็น | `setupSheets` | สร้างแท็บ Inspections / DefectLog พร้อมหัวตาราง |

## กล่องโต้ตอบที่ใช้ได้

```javascript
var ui = SpreadsheetApp.getUi();

// 1. แจ้งเตือนเฉย ๆ
ui.alert('หัวข้อ', 'ข้อความ', ui.ButtonSet.OK);

// 2. ถามยืนยัน ใช้ก่อนทำอะไรที่ลบไม่ได้
if (ui.alert('ยืนยัน', 'ลบเลยไหม?', ui.ButtonSet.YES_NO) === ui.Button.YES) {
  // ลบ
}

// 3. ให้พิมพ์ข้อความเข้ามา
var res = ui.prompt('ใส่รหัส', 'พิมพ์รหัส 3 หลัก', ui.ButtonSet.OK_CANCEL);
if (res.getSelectedButton() === ui.Button.OK) {
  var text = res.getResponseText();
}

// 4. หน้าจอ HTML เต็มรูปแบบ (ทำฟอร์มสวย ๆ ได้)
ui.showModalDialog(HtmlService.createHtmlOutput('<h1>สวัสดี</h1>'), 'หัวข้อ');
ui.showSidebar(HtmlService.createHtmlOutput('<h1>แถบข้าง</h1>'));
```

## ทำอะไรได้บ้าง (นอกจากเมนู)

Apps Script เข้าถึงบริการของ Google ได้เกือบทั้งหมด **ในสิทธิ์ของคนที่กด Deploy**

| บริการ | ตัวอย่างที่ทำได้จริง |
|---|---|
| **SpreadsheetApp** | อ่าน/เขียน/จัดรูปแบบ/สร้างแท็บ/ใส่สูตร/สร้างกราฟ |
| **DriveApp** | สร้างโฟลเดอร์ อัปโหลดไฟล์ ตั้งสิทธิ์แชร์ (ระบบนี้ใช้เก็บรูป defect) |
| **GmailApp / MailApp** | ส่งอีเมล — เช่น สรุป defect ประจำวันส่งเข้าเมลหัวหน้าอัตโนมัติ |
| **CalendarApp** | สร้างนัดหมาย — เช่น ลงตารางวันนัดผู้รับเหมาเข้าแก้งาน |
| **UrlFetchApp** | ยิง API ภายนอก — เช่น ส่งแจ้งเตือนเข้า **LINE Notify** หรือ Slack |
| **PropertiesService** | เก็บค่าตั้งค่าลับ ๆ เช่นรหัสผ่าน (ไม่โผล่ในโค้ดหน้าเว็บ) |
| **HtmlService** | ทำหน้าเว็บ / Web App — คือตัวที่รับข้อมูลจากฟอร์มมือถือของเรา |
| **LockService** | กันคนบันทึกพร้อมกันแล้วข้อมูลชนกัน |

### ตัวอย่างที่ต่อยอดได้กับระบบนี้

```javascript
// ส่ง LINE แจ้งเตือนเมื่อพบ defect เกิน 50 จุดในห้องเดียว
UrlFetchApp.fetch('https://notify-api.line.me/api/notify', {
  method: 'post',
  headers: { Authorization: 'Bearer ' + TOKEN },
  payload: { message: 'ห้อง 510 พบ defect 56 จุด' },
});

// ส่งสรุปประจำวันเข้าเมล
MailApp.sendEmail('boss@hotel.com', 'สรุป Defect วันนี้', 'พบรวม 92 จุด');
```

## ตั้งเวลาให้ทำงานเองได้ด้วย (Trigger)

ไม่ต้องรอคนกดเมนู — ตั้งให้รันเองตามเวลาหรือตามเหตุการณ์

**นาฬิกา ⏰ ในแถบซ้ายของ Apps Script → Add Trigger**

- **Time-driven** — ทุกชั่วโมง / ทุกวันตอน 8 โมง / ทุกสัปดาห์
  เช่น ส่งสรุป defect เข้าเมลทุกเช้า
- **On form submit** — เมื่อมีคนส่ง Google Form
- **On edit / On change** — เมื่อมีคนแก้ชีท
- **On open** — เมื่อเปิดชีท (`onOpen` ใช้ตัวนี้ ไม่ต้องตั้งเอง)

---

## ข้อจำกัดที่ต้องรู้

| เรื่อง | รายละเอียด |
|---|---|
| **เมนูไม่อัปเดตเอง** | แก้โค้ดแล้วต้อง Ctrl+S + **รีเฟรชหน้าชีท** |
| **`getUi()` ใช้ได้เฉพาะตอนคนกด** | เรียกจาก `doPost` หรือ trigger ตามเวลาไม่ได้ จะ error |
| **รันได้ไม่เกิน 6 นาที** | งานหนักต้องซอยเป็นรอบ ๆ |
| **ต้องขออนุญาตครั้งแรก** | กด Run ครั้งแรกจะเด้งขอสิทธิ์ ต้อง Advanced → Go to → Allow |
| **Deploy กับ Save คนละเรื่อง** | เมนู/Run ใช้โค้ดที่ **Save** · หน้าเว็บใช้โค้ดที่ **Deploy** |
| **โควตารายวัน** | ส่งอีเมล/ยิง API มีลิมิตต่อวัน (บัญชีฟรีน้อยกว่า Workspace) |

---

## สรุปสั้น ๆ ถ้าจะสร้างเอง

1. เปิดชีท → **Extensions → Apps Script**
2. เขียน `onOpen()` ตามตัวอย่างข้างบน + ฟังก์ชันที่อยากให้ทำงาน
3. **Ctrl+S**
4. **รีเฟรชหน้าชีท** → เมนูโผล่
5. กดครั้งแรกจะขอสิทธิ์ → Allow

ถ้าอยากให้หน้าเว็บภายนอกเรียกได้ด้วย ต้องเขียน `doPost(e)` / `doGet(e)`
แล้ว **Deploy → Web app** เพิ่ม (แบบที่ระบบนี้ใช้)
